04 / SELECTED WORK

Engineering projects

ACADEMIC PROJECT · B.TECH

Automatic Phase Selection in a Three-Phase Supply System

Project Overview

Designed and implemented an automatic phase selection system to maintain a continuous single-phase supply. The system monitors three-phase conditions, detects phase failure and automatically switches the load to an available healthy phase.

Objectives & Key Features

  • Monitor the availability of all three phases.
  • Detect phase failure and initiate automatic switching.
  • Measure load current and verify backup supply.
  • Display system information through an LCD.
  • Monitor phase conditions remotely using server.
  • Enter a safe state during simultaneous multi-phase failure.

Hardware & Technologies

Arduino Mega 2560 · ACS712 Current Sensors · Voltage Sensing Circuits · ESP8266 · Relay Board · 16×2 LCD · Embedded C · UART · I2C · Blynk

Experimental Results

< 200 ms Phase fault detection
1.7 seconds Load switchover
3 seconds Phase recovery stability
< 3 seconds Blynk data update

Engineering Workflow & Responsibilities

  1. Component Selection & Understanding

    Studied electrical and electronic components, datasheets, ratings, reliability, thermal performance and safety requirements involved in EV charger systems.

    Gained practical exposure to charger assembly, electrical wiring, harness routing, mechanical integration, schematic interpretation, continuity testing and quality inspections.
