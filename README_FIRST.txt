HARsha's Engineering Portfolio — Starter Website

WHAT'S INCLUDED
- index.html: website content and structure
- style.css: visual design and responsive layout
- script.js: interactive Beyond Engineering flipbook and page controls
- assets/: add your own photos here

IMPORTANT CONTENT SEPARATION
The main website is for engineering: About, Skills, Projects, Documentation and Experience.
The Beyond Engineering flipbook is ONLY for public speaking, volunteering, social contributions,
leadership, event organising, awards, certificates, medals, mementos and memories.

HOW TO PREVIEW ON YOUR COMPUTER
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It should open in your browser.
4. To edit text, open index.html in a text editor such as Visual Studio Code.
   You do not need to understand the code to begin; change the clearly marked sample text.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to https://github.com/
2. Create a NEW PUBLIC repository named exactly: YOUR-USERNAME.github.io
3. Open the repository and choose Add file > Upload files.
4. Upload index.html, style.css, script.js, README_FIRST.txt and the assets folder.
5. Click Commit changes.
6. Open repository Settings > Pages.
7. Under Build and deployment choose Deploy from a branch.
8. Select branch main and folder /(root), then Save.
9. Wait a few minutes, then visit https://YOUR-USERNAME.github.io/

BEFORE PUBLISHING
- Replace sample biography and project text with accurate information.
- Add your own photographs to assets/ and update the matching image paths in index.html.
- Do not publish private contact details, personal documents, or photos of others without permission.
- Do not claim awards, event roles or project results unless they are accurate.
